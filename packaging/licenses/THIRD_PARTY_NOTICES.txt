Audio Assembler - third-party software
=====================================

Audio Assembler itself is released under the MIT License (Audio-Assembler-MIT.txt).
The Windows application also contains the following separate open-source components.
Each keeps its own license. Full license texts are in this folder.


1. FFmpeg (audio engine)
   Files:    _internal\ffmpeg\ffmpeg.exe and the av*.dll / sw*.dll files next to it
   Version:  n9.0.2-57-gd838f9f9ae, Windows x64, "lgpl-shared" build
   License:  GNU Lesser General Public License, version 3 or later (LGPL-3.0.txt, GPL-3.0.txt).
             This build contains no GPL-only or non-free parts.
   Source:   https://git.ffmpeg.org/ffmpeg.git  (commit d838f9f9ae)
   Build:    https://github.com/BtbN/FFmpeg-Builds  (release autobuild-2026-11-17-12-40);
             the build scripts list every library compiled into these files, with its source.
   Audio Assembler runs ffmpeg.exe as a separate program. You may replace the files in
   _internal\ffmpeg with your own build of the same FFmpeg version.

   The FFmpeg libraries in this build include the LAME MP3 encoder (LGPL-2.0-or-later,
   https://lame.sourceforge.io) and other open-source libraries named in the build scripts above.

2. Qt 6 and Qt for Python (PySide6, Shiboken6) 6.12.0 (window toolkit)
